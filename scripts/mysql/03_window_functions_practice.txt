OVER() clause constructs a window. When it's empty, the window will include all records.

OVER(Partition by ) ---is used to form rows into group of row.

Window functions in MySQL

Window functions allow you to perform calculations across a set of rows that are related to the current row within a result set. They are useful for running totals, ranking, and moving averages.
Window functions:
1. ROW_NUMBER(): Assigns a unique row number to each row in the result set.
2. RANK(): Assigns a rank to each row, with gaps for ties.
3. DENSE_RANK(): Similar to RANK(), but without gaps for ties.
4. SUM(): Computes the sum of values over a specified window.
5. AVG(): Computes the average value over a specified window.

A window function performs a calculation across a set of rows that are related to the current row.
Aggregate functions (SUM, AVG, COUNT, etc.) usually aggregate rows into one result.
Window functions keep the individual rows but add an extra "calculated value" alongside them.


1. Display employee details along with the total number of employees.
SELECT emp_id, name, department,
       COUNT(*) OVER() AS total_employees

2. Show each employee’s salary along with the average salary of all employees.
SELECT ename, sal,
       AVG(sal) OVER() AS avg_salary
FROM emp;

3. Display employee salary along with the maximum salary in the company.
SELECT ename, sal,
       max(sal) OVER() AS max_salary
FROM emp;

4. Show each employee’s salary and total salary of all employees.
SELECT ename, sal,
       sum(sal) OVER() AS total_salary
FROM emp;

5. Display employee salaries and average salary per department.
SELECT ename, deptno, sal,
       avg(sal) OVER(partition by deptno) AS dept_avg_salary
FROM emp;

6. Rank employees based on salary.
SELECT name, salary,
       RANK() OVER(ORDER BY salary DESC) AS salary_rank
FROM Employees;

FROM (

             ROW_NUMBER() OVER(PARTITION BY deptno ORDER BY sal DESC) AS rn

10. Show the top 3 highest-paid employees in each department.
SELECT *
FROM (
      SELECT name, department, salary,
             ROW_NUMBER() OVER(PARTITION BY department ORDER BY salary DESC) AS rn
      FROM Employees
     ) t
WHERE rn <= 3;
